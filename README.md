# ☕ Froth and Friends Café — Official Website

A premium, modern, and fully responsive café website for **Froth and Friends Café**, located in Vijayawada, Andhra Pradesh.

---

## 🌐 Live Preview

Open `index.html` in any browser — no build step required. Works directly in VS Code with Live Server.

---

## 📁 Project Structure

```
froth-and-friends-cafe/
├── index.html          # Complete single-file website
└── README.md           # Project documentation
```

---

## ✨ Features

- **Hero Section** – Full-screen café background, headline, CTA buttons, animated scroll indicator
- **Stats Bar** – Rating, menu items, hours, vibes
- **About Section** – Story, features, floating image collage
- **Menu Section** – Tabbed filter (Coffee, Pizza, Pasta, Burgers, Sandwiches, Desserts) with image cards
- **Gallery** – Masonry-style grid with hover overlays
- **Reviews** – 6 customer testimonials with star ratings
- **Contact** – Address, phone, hours, embedded Google Map, WhatsApp & call buttons
- **Footer** – Branding, quick links, social icons, contact info

## 🚀 Running Locally

## 🌍 Deployment (GitHub Pages)

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Source: `main` branch, `/ (root)`
4. Your site will be live at `https://yourusername.github.io/repo-name/`

---

## 📝 Customization

- **Colors** — Edit CSS variables in `:root` at the top of `index.html`
- **Menu Items** — Edit the `menuItems` array in the `<script>` section
- **Google Map** — Replace the `src` in the `<iframe>` with your own Google Maps embed URL
- **WhatsApp** — The number `919705981111` can be updated in all `wa.me` links
- **Images** — Replace Unsplash URLs with your own photos
